# Мониторинг сайтов и лент

Специалист тратил по несколько часов в день на просмотр сайтов и чатов. Важные новости терялись в рекламе.

Бот обходит список источников, отсекает рекламу и ненужные темы и присылает в Telegram короткую выжимку со ссылкой на оригинал.

Заказчик получает новости по своему профилю без информационного шума.

## Как попробовать

Нужны Windows, Telegram и [Python](https://www.python.org/downloads/) 3.10 или новее. При установке Python поставьте галочку **Add python.exe to PATH**.

Чтобы бот делал короткие выжимки, понадобится ещё ключ из кабинета [ProxyAPI](https://proxyapi.ru/). Без ключа бот запустится, но саммари может не собраться.

1. На этой странице нажмите **Code** → **Download ZIP** и распакуйте архив.
2. Создайте бота: [@BotFather](https://t.me/BotFather) → `/newbot`. Сохраните токен.
3. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
4. Скопируйте файл `.env.example` и назовите копию `.env`. Откройте его блокнотом.
5. Вставьте токен в `TELEGRAM_BOT_TOKEN=`, свой ID в `ADMIN_TELEGRAM_IDS=`, ключ — в `PROXYAPI_KEY=`. Сохраните.
6. Откройте папку проекта, в адресной строке напишите `cmd`, Enter. Затем две команды, каждая с Enter:

```cmd
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Первый раз установка займёт несколько минут.

7. Дважды щёлкните `run.bat`. Окно не закрывайте.
8. В Telegram откройте своего бота, нажмите Start.
9. Добавьте любой новостной сайт кнопкой «Добавить источник» или напишите боту ссылку.

По умолчанию бот проверяет источники раз в 5 минут.

## Как пользоваться

1. Добавляйте сайты и ленты, которые нужно смотреть.
2. Список источников и удаление — кнопками в боте.
3. Новая публикация приходит сообщением: заголовок, два-три предложения, ссылка.
